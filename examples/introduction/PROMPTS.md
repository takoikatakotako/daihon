# キャラクター画像の生成プロンプト

`assets/senpai/` と `assets/kouhai/` の立ち絵を ChatGPT で生成するためのプロンプト。
各ブロックをそのまま貼れば1枚できる。

**キャラごとに新しいチャットを1つ使い、smile → 他の表情の順に同じチャットで作る。**
2枚目以降は直前の画像を編集させるので、顔や服がそろう。

## つまずきやすいところ

- 編集を重ねると体の位置が少しずつずれる。ずれたら smile の画像を貼り直して
  「この画像を元に」と頼む。
- 背景が白や市松模様で描き込まれ、透過になっていないことがある。そのときは
  「背景を本当の透過にして」と追加で頼む。
- 1キャラの画像はすべて同じキャンバスサイズにする。違うと表情の切り替えで位置がずれる。

# 小物・背景の生成プロンプト

キャラと同じチャットで作るか、先輩の `smile.png` を添付してから貼る。絵柄がそろう。
小物は `assets/images/`、背景は `assets/bg/` に置く。

## images/tv_video_hensyu_hard.png

```
添付した画像と同じ絵柄（線の太さ・塗り・目の描き方）で、小物イラストを1枚作ってください。

モチーフ：徹夜で動画編集をしてぐったりしている人。机に向かって座り、モニターには動画編集ソフトのタイムラインとプレビュー画面が映っている。目の下にくま、髪は少しボサボサ。目は開いている。
- 斜め前から見た構図。人・机・モニターがひとまとまりで画像に収まる
- 背景は完全な透過（PNG）。床や影は付けない
- 画像サイズは 1536x1024（横長）
- 文字やロゴは入れない
```

添付した画像と同じ絵柄（線の太さ・塗り）で、小物イラストを1枚作ってください。
